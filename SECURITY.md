# Security

Frametide runs with administrator rights and changes Windows settings, services and GPU parameters.
Every change it makes is listed in its log and backed up in `C:\ProgramData\Frametide\journal.json`.

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private vulnerability reporting
("Security" tab > "Report a vulnerability") on this repository.

## Downloads
Only install Frametide from the official releases of `github.com/narucx/frametide`.
